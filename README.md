# СпасиДете.БГ — нов сайт / new website

Статичен двуезичен сайт (български / английски) за дирекция „Киберпрестъпност“ при ГДБОП-МВР.
A static bilingual site (Bulgarian / English) for the Cybercrime Directorate at GDBOP, Ministry of Interior.

Без рамки, без билд стъпка за разгръщане, без бекенд — само HTML, CSS и малко ванилен JavaScript.
No frameworks, no build step for deployment, no backend — just HTML, CSS and a little vanilla JavaScript.

## 2. Разгръщане / Deployment

Сайтът е напълно статичен. Качете съдържанието на папката както е — на всеки уеб сървър,
на GitHub Pages, на Netlify или на Cloudflare Pages. Не е нужна нито база данни, нито PHP.

The site is fully static. Upload the contents of the folder as they are — to any web server,
to GitHub Pages, Netlify or Cloudflare Pages. No database and no PHP are required.

**Сайтът вече е качен / the site is already deployed**

| | |
|---|---|
| Хранилище | https://github.com/Cyb3r-Pony/spasidete.bg |
| Адрес | https://cyb3r-pony.github.io/spasidete.bg/ |
| Клон | `main`, коренова папка `/` |

Всяко бутане към `main` преиздава сайта за около минута. За да качите промяна:

```
git add -A
git commit -m "кратко описание на промяната"
git push
```

**Собственият домейн spasidete.bg.** Файлът `CNAME` стои в папката, но е изваден от
хранилището чрез `.gitignore`, защото GitHub Pages го приема като команда „сервирай този

## 3. Двата езика / The two languages

Всеки текстов блок съществува два пъти в HTML-а — веднъж с `lang="bg"` и веднъж с `lang="en"`.
CSS скрива неизбрания език, а превключвателят БГ / EN в горния десен ъгъл запомня избора
(`localStorage`). Работи и с адрес: `index.html?lang=en`.

Every text block exists twice in the HTML — once with `lang="bg"` and once with `lang="en"`.
CSS hides the language that is not selected; the БГ / EN switch in the top-right corner remembers
the choice (`localStorage`). It also works via the address: `index.html?lang=en`.

**За да редактирате текст:** намерете изречението в HTML файла и променете и двата варианта,
които стоят един до друг. Няма отделен файл с преводи.

**To edit text:** find the sentence in the HTML file and change both variants, which sit next
to each other. There is no separate translation file.

## 4. Генераторът build.py (по избор) / The build.py generator (optional)

HTML файловете са завършени и могат да се редактират директно. `build.py` е скриптът, който ги
е създал — ако предпочитате да поддържате съдържанието на едно място (новини, телефонни линии,
полезни връзки са описани като списъци в началото на файла), редактирайте него и изпълнете:

```
python3 build.py
```

Това презаписва всички `.html` файлове. Ако редактирате HTML на ръка, **не** изпълнявайте скрипта
после — ще загубите промените.

The HTML files are finished and can be edited directly. `build.py` is the script that produced
them — if you prefer to keep the content in one place (news, helplines and resources are declared
as lists at the top of the file), edit it and run `python3 build.py`. That overwrites all `.html`
files, so do not run it after editing the HTML by hand.

## 6. Оформление / The visual system

**Темата.** Сайтът е на Министерството на вътрешните работи и говори за агресията в
детския свят във всичките ѝ форми — към детето, от детето и между децата, в училище, на
улицата и онлайн. Препратките към ГДБОП и дирекция „Киберпрестъпност“ остават, но като
канали за сигнал, не като собственик на сайта.

**Лентата.** Един ред: лого вляво, разделите точно в средата (три колони с еднакви
странични коловози, затова менюто стои центрирано при всяка ширина), превключвател на
езика и едър бутон „Подай сигнал“ вдясно. Под 1180 px разделите падат в меню, а на
телефони под 370 px превключвателят на езика слиза в самото меню, за да остане място за
името на сайта.

**Логото.** Три файла, всичките с WebP и PNG:

| Файл | Какво е | Къде стои |
|---|---|---|
| `logo-spasidete` | щит + надпис „СпасиДете.БГ“ | лентата горе вляво |
| `logo-mark` | само щитът с дланта и детето | футърът и иконите на браузъра |
| `logo-full` | логото заедно с реда на МВР | резерва за печат и документи |

Надписът в лентата идва от самото лого, затова до него няма отделен текст — ако смените
логото, запазете съотношението (около 2,4:1), за да не се разваля лентата.

**Иконите на браузъра** се правят от `logo-mark`:

| Файл | За какво е |
|---|---|
| `favicon.ico` (в корена) | 16/24/32/48/64 px в един файл — това търси Safari на първо място |
| `assets/img/icon-32.png` | иконата в раздела при повечето браузъри |
| `assets/img/icon-192.png` | начален екран на Android, списъци с приложения |
| `apple-touch-icon.png` (в корена) | начален екран на iPhone и iPad |
| `assets/img/mask-icon.svg` | закачен раздел в Safari — едноцветен силует |

Safari пази иконите в собствен кеш, който не се съобразява със заглавията за
кеширане и може да задържи стара икона със седмици. Затова при смяна на иконата
**сменете и имената на файловете** — нов адрес е единственото, което Safari
пречупва със сигурност. (За да се види веднага на един компютър: Safari →
Settings → Advanced → Show features for web developers, после Develop → Empty
Caches; или Safari → Settings → Privacy → Manage Website Data → изтриване на
записа за сайта.)

**Адресът на сайта.** В `build.py` има една константа `SITE_BASE` — от нея идват
`og:url`, каноничните връзки, адресът на картинката за споделяне и `sitemap.xml`.
Когато spasidete.bg започне да сочи към GitHub Pages, сменете само нея.

**Цветовете на секциите.** Четири приглушени тона, всеки със своя тема. Тоновете са
бледи нарочно — текстът върху тях има същия контраст, както върху бяло (проверено:
най-ниската стойност в сайта е 4,98:1 при изискване 4,5:1).

| Клас | Тон | Кога се ползва |
|---|---|---|
| `section--sky` | светло синьо `#e6eefa` | обяснение и ориентиране — какво е агресия, материали, контакти |
| `section--azure` | по-наситено синьо `#d5e3f6` | какво помага — съвети, реакция, кампании, новини |
| `section--rose` | бледо червено `#fbefec` | опасност и спешност — телефонни линии, подаване на сигнал |
| `section--sand` | топло жълто `#fbf3e3` | внимание и данни — признаци, статистика, често задавани въпроси |

Зелено не се ползва никъде. Върху `section--azure` връзките и червеното се
затъмняват автоматично, за да остане контрастът над 4,5:1.

Всяка цветна секция пренастройва `--line`, `--ink-3` и `--accent`, затова картите,
кутиите и табовете вътре се нагаждат сами. Белите секции остават за дълъг текст. Две
тонирани секции рядко стоят една до друга; когато се случи, тънка линия показва, че
смяната е нарочна.

За да оцветите секция, добавете класа в `build.py`:
`<section class="section section--azure">`. Нищо друго не е нужно.

## 7. Достъпност и техническо / Accessibility and technical notes

- Пропускаща връзка към съдържанието, `aria-current` за текущата страница, `aria-expanded`
  за менюто и разгъваемите новини, `aria-controls`/`aria-labelledby` между табовете и
  панелите им, клавиатурна навигация в таб-групите (стрелки), затваряне на мобилното меню
  с Esc или щракване извън него. Декоративните емблеми са с празен `alt`, за да не се
  повтарят от екранните четци.
- Телефонните номера са `tel:` връзки — на мобилно устройство се набират с едно докосване.
- Проверено при ширина 390 px, 1180 px и 1280 px: без хоризонтално превъртане, без грешки
  в конзолата, всички вътрешни връзки и файлове се откриват.
- Сайтът не зарежда нищо от Google Fonts и не прави нито една външна заявка при отваряне.
  Единственото външно съдържание е видеото в „Кампании“ и то се зарежда само след клик.
- Стил за печат: навигацията и лентите се скриват.
- Поддържа `prefers-reduced-motion`.

## 9. Бързина и мобилна версия (октомври 2026)

**Снимките** се сервират в четири размера и два формата. Браузърът избира най-лекия файл,
който му върши работа: WebP, ако го поддържа (всички съвременни браузъри), иначе JPEG.

```
hero.jpg        1600 px   оригинал
hero-md.webp     960 px   за широка колона на десктоп
hero-sm.webp     800 px   за таблет и среден екран
hero-xs.webp     480 px   за телефон
```

Вариантите се правят веднъж и стоят в `assets/img/photos/`. Ако добавите снимка, сложете
само оригиналния `.jpg` там и изпълнете:

```
python3 tools/make-images.py
```

Скриптът прави липсващите варианти и не пипа съществуващите. `build.py` слага в `srcset`
само онези варианти, които наистина съществуват на диска — ако ги няма, страницата пак
работи, просто с по-големия файл.

**Емблемите** се сервират в умален вид (192 px). Никъде на сайта не се показват по-широки
от 58 CSS px, така че оригиналът от 341 px беше излишен товар на всяка страница. При смяна
на емблема заменете PNG файла и изпълнете `python3 tools/make-emblems.py`.

**Видеата в „Кампании“** не се зареждат при отваряне на страницата. Показва се снимка
с бутон „Пусни“; плейърът на YouTube тръгва чак при натискане и то през
`youtube-nocookie.com`. Това означава, че YouTube не слага бисквитки, докато посетителят
не поиска видеото.

**Какво още е направено**

- Премахнат е Google Fonts. Сайтът ползва системния шрифт и не прави никаква външна
  заявка при отваряне. Това спестява два `preconnect`, един блокиращ CSS файл и шрифтовите
  файлове, а и е по-чисто откъм GDPR за сайт на МВР.
- Водещата снимка на началната страница се предзарежда (`rel="preload"`) и е с
  `fetchpriority="high"`; всички останали снимки са `loading="lazy"` и `decoding="async"`.
- Всяка снимка има `width` и `height`, така че страницата не подскача при зареждане.
- Скриптът е с `defer`.
- Таблицата с областните дирекции се превръща в списък от карти под 760 px — вече не
  се превърта настрани на телефон.
- Полетата на формуляра са 16 px на телефон, за да не увеличава iOS при фокус.
- Горната лента остава тънка, но зоната за докосване на емблемата, превключвателя на
  езика, бутона „Подай сигнал“ и точките на въртележката е разширена невидимо до 44 px.
- Водещата снимка е с изрязване 5:4 на телефон вместо 16:9, за да не е прекалено ниска.

**Какво остава за сървъра.** CSS е 43 KB, а скриптът — 24 KB. Включете gzip или brotli
на хостинга и те падат до около 9 и 7 KB. GitHub Pages, Netlify и Cloudflare Pages го
правят автоматично.

## 10. Навигация и препратки (октомври 2026)

**Бутонът „Начало“ го няма в менюто.** Заглавието **СпасиДете.БГ** с емблемата вляво е
връзката към началната страница — на компютър и на телефон. Ако сте вече на началната
страница, натискането плъзга плавно до горе, без да презарежда.

**Смяна на раздел винаги започва отгоре.** Когато посетителят отвори друг раздел от менюто
или смени таб в „Съвети“, страницата започва от началото, а не от средата. Това важи и за
двете версии.

**Контекстните бутони водят точно до реда, за който се отнасят.** „Свържете се с нас“ не
отваря просто „Контакти“, а застава на блока с адреса и телефона. Котвите в сайта:

## 11. Проверки преди качване / Pre-flight checks

Направени са на 1 октомври 2026 г. върху готовите файлове:

- **Формулярът работи и на GitHub Pages.** Той няма `action` и не праща нищо към сървър —
  съставя писмо и отваря пощенската програма на посетителя. Затова работи на всеки статичен
  хостинг. Сайтът не записва и не изпраща нищо от написаното.
- **28-те областни дирекции** имат адрес за писмо. ОДМВР Бургас не публикува електронен
  адрес на mvr.bg, затова писмото за Бургас тръгва към приемната на МВР
  (`priemna@mvr.bg`) — в панела „Към кого отива“ това е написано ясно.
- **Дължината на писмото.** Кирилицата заема по шест знака след кодиране, затова дори кратък
  сигнал дава дълъг адрес. Границата е 6000 знака; над нея формулярът насочва към бутона
  „Копирай текста“, вместо да отвори отрязано писмо.
- **Няма абсолютни пътища** (`/assets/...`), няма главни букви в имената на файловете и има
  `.nojekyll` — трите неща, в които сайт се чупи на GitHub Pages.
- **Няма счупени връзки и котви** — проверени са всички вътрешни адреси във всички 11 страници.
- **Няма повтарящи се `id`**, всяка снимка има `alt`, `width` и `height`, всяка страница има
  `<h1>`, `<main>`, връзка за прескачане и правилен ред на заглавията.
- **Няма грешки в конзолата** на нито една страница, на компютър и на телефон.
- **Няма хоризонтално превъртане** при 390 px.
- **Зоните за докосване** отговарят на WCAG 2.2 AA (минимум 24 px); единственото изключение
  са връзките вътре в изречение, за които стандартът изрично не поставя изискване.

Проверките могат да се повторят с браузър — няма нужда от инструмент; важните неща са
изброени по-горе, за да се знае какво точно е гледано.
